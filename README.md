# basis

basis is a set of packages that give a firm's APIs, batch jobs, portfolio optimizers and React UIs one shape, built for
a codebase that agents write and checks review: `basis-core`, `basis-job`, `basis-api`, `optim`, `@basis/ui` and
`@basis/parallax`. The name is a placeholder.

Nothing is built yet. The repo holds the design and the build order:

- [The basis design](docs/design.md): what each package is, how they fit, and why.
- [Roadmap](docs/roadmap.md): the phases, the steps in each, and which run at the same time.

basis grows out of [portfolio-optim](https://github.com/jacobragsdale/portfolio-optim),
[etl-framework](https://github.com/jacobragsdale/etl-framework) and
[parallax](https://github.com/jacobragsdale/parallax), which move into it during the roadmap's phases 1, 3 and 4.
